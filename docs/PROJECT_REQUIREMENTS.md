# 项目评价约定

本包服务于 2.5D Mesh 的固定十场景 M3。要求真实 GT/PRED 同坐标对照、差异图以及分类/边界/形状/匹配逐图判断。材料缺失时评价 incomplete；complete 与模型 pass/fail/inconclusive 分别记录。

M3 失败是有效结果，供下一方案审议。晋升和整体达标需同时依据已登记主指标、类别/场景护栏、真实 M2 及成本。本包 result.json 的 goal_met 始终为空、promotion_decision 要求项目决策，不自行晋升候选。

本项目 2026-09-29 后续约定已提出：十图是深度复核预算。原留出索引含 99 场景 10,568 帧，旧十帧只占约 0.095%；广覆盖自动筛查须另行冻结数据和验证逐帧适配器。固定短板集用于同口径比较，动态失败集用于寻找新故障，成员变化不能直接作两轮均分差值。

新渲染规则固定为 0.1m XY 网格、每场景 GT/PRED 联合 XY 范围、GT/PRED 分别栅格化、稳定场景顺序、众数平局取最小 label。比较不同候选时须同时检查 bounds_xy、GT 输入哈希及协议摘要；若 GT 查询网格变化则不能宣称严格同网格改善。正式源 mesh GT 哈希一致也不自动说明查询网格一致。

正式 pillar M1 未在历史连续 head 中提供，surface IoU 和 BEV 召回不代填正式 M1。语义查询网格 z 不能证明真实高度 M2；需从远端真实 drivable-height MAE 及有效点数补齐。

## BMAD-ML 接入边界

可在项目评价阶段调用本 CLI，读取 run-manifest.json、visual-review.json 和 result.json；缺必交证据不能结项，不能静默删除 M3 要求。现有运行时的 Mesh 收集、视觉回执核验及候选晋升门禁尚需对应适配。交付本包没有修改活动研究或把 M3 冒充已接入通用二分类收集器。

新协议或候选/目标规则改变时新建版本并审议；旧结果、原任务和原冻结保持。不新建调度器，不因使用可视化包启动训练或恢复定时器。
